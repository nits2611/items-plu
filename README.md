# Nesters / Save-On PLU Lookup — Installable PWA

This is the installable PWA version.

## Important
To install on your phone, the app must be opened from a web server, not usually from a raw local file.

Best simple options:
1. Upload this folder to GitHub Pages.
2. Upload this folder to Netlify.
3. Run it locally on your computer with a small web server.

## Android install
Open the hosted URL in Chrome, then tap:
Menu → Add to Home screen / Install app.

## Updating data
Use the in-app Upload CSV button, or replace `items.csv` and rebuild/reupload.
